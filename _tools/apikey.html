Get an xrpl.to API key

Runs locally. Your private key never leaves GemWallet — it signs a short text string and only the signature is sent.

1Unlock the GemWallet extension in this browser.
2Click below. GemWallet will ask you to approve reading your address, then to sign the message <your-address>:<timestamp>.
3Copy the key immediately. xrpl.to shows it once and cannot retrieve it later.
